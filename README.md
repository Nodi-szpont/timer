# Timer

Aplikacja do mierzenia czasu - wyświetla odliczanie czasowe.

## Nauczasz się:
- **Android Activity** - podstawowa struktura aplikacji
- **Layout** - budowanie interfejsu użytkownika
- **EdgeToEdge** - rozszerzanie interfejsu na całą powierzchnię ekranu
- **WindowInsets** - obsługa pasków systemowych
